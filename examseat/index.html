노란 칸(그날 뒤에 시험이 남아 있는 미응시) 학생들이 기다릴 장소를 적어 주세요. 교시마다 한 곳을 적거나, 인원이 많으면 반별로 나누기로 반마다 다른 장소를 줄 수 있습니다. 적은 장소는 개인 시간표 칸(“대기: ○○”)과 엑셀의 대기 명단 시트에 들어갑니다.

교시 · 고사장 · 과목마다 봉투 표지를 한 장씩(A4 가로) 만듭니다. 응시 인원과 좌석·학번·성명은 자동으로 채워지고, 과목코드·문제면수는 과목마다 한 번만 적으면 됩니다. 담당교사는 강좌목록의 지도교사로 미리 채워 두었습니다.

학생이 휴대폰으로 학번·이름을 넣으면 자기 시간표만 보는 페이지를 선생님 구글 계정에 만듭니다. 학생 정보는 선생님 구글 시트에만 있고, 시트는 공유하지 않으므로 다른 학생 것은 볼 수 없습니다. 처음 한 번 설정해 두면 그다음부터는 올리기 버튼 하나로 바뀐 고사실·대기 장소가 학생 페이지에 바로 반영됩니다.

켜면 시트에 '확인코드(담임 배부용)' 명단이 함께 들어갑니다. 담임 선생님이 학생에게 나눠 주세요. 번호는 이 브라우저에 기억되어 다음에 만들어도 같습니다.

학생에게 공유하기
위에 웹 앱 주소를 넣으면 QR 코드가 만들어집니다.
처음 한 번 아래 설정을 마치고 주소를 넣어 두면, 다음부터는 변환 후 이 버튼만 누르면 학생 페이지가 바로 바뀝니다.
처음 한 번 설정하기 (약 3분)
  1. 빈 구글 시트 만들기Google Drive에서 새로 만들기 → Google 스프레드시트. 이름은 자유롭게(예: 시험 시간표 조회). 학생에게 이 시트는 공유하지 마세요.
  2. 조회 코드 붙여넣기그 시트에서 확장 프로그램 → Apps Script를 열고, 원래 내용을 지운 뒤 아래 코드를 통째로 붙여넣고 저장(💾). 코드에는 이 생성기만 데이터를 올릴 수 있는 비밀 열쇠가 들어 있습니다.
    복사가 안 되면 아래 칸을 눌러 전체 선택(Ctrl+A) 후 복사하세요.
  3. 웹 앱으로 배포
    • 처음 배포할 때: 오른쪽 위 배포 → 새 배포 → 톱니바퀴에서 웹 앱 선택 → 실행 사용자 나, 액세스 권한 모든 사용자 → 배포
    • 코드를 다시 붙여넣었을 때: 배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포 (저장만 하면 반영되지 않습니다. 주소는 그대로)
    • 권한 창이 뜨면 본인 계정으로 허용하세요. ‘확인되지 않은 앱’이 나오면 고급 → 이동을 누르면 됩니다.
  4. 주소 넣기배포 후 나온 웹 앱 URL을 위 칸에 붙여넣고 학생 조회 페이지에 올리기. 학생들에게는 주소 복사나 QR 안내문으로 공유하면 됩니다.
자동 올리기가 안 되는 환경이면:→ 시트에서 파일 → 가져오기 → ‘스프레드시트 바꾸기’
학번과 이름은 친구끼리 서로 알 수 있으니, 다른 학생 것을 볼 수 없게 하려면 확인코드를 켜세요. 같은 학번으로 5번 틀리면 10분 동안 조회가 막힙니다. 학교 구글 워크스페이스 계정이라면 5번에서 액세스 권한을 ‘○○고 내 모든 사용자’로 하면 학교 계정으로 로그인한 사람만 들어올 수 있습니다.
